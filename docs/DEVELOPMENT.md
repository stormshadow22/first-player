# Разработка

Запуск и распределение работы — README.md; сигнатуры — docs/CONTRACT.md.
Python 3.11; универсальный requirements.lock включает зависимости Windows/Linux.

После изменения requirements.txt обновить lock:
uv pip compile --universal --python-version 3.11 requirements.txt -o requirements.lock

После интеграции: pytest, ruff, smoke, acceptance, затем реальные данные.
Make train/index/eval ожидают будущие скрипты владельцев B/C/D.

Метрики локальны процессу. /metrics показывает текущие счётчики; metrics.json
экспортируется при штатной остановке API или завершении predict.
Принудительное завершение Windows-процесса может не вызвать lifespan cleanup;
acceptance сохраняет /metrics в http-metrics.json перед остановкой.
Статистика стадий включает число вызовов/ошибок, mean/p95 задержку.
Bench вычисляет среднее за прогон по разности счётчиков и указывает владельца
самой медленной стадии. Запускайте один worker без посторонней нагрузки.
Samples хранятся in-memory: это хакатонный сервис, не бесконечный uptime.

LLM: .env читается автоматически, shell имеет приоритет. Пример выбранной модели,
дата сверки и официальный источник прайса — README.md и .env.example.
Ключи не коммитить. Предварительная оценка: UTF-8 bytes с запасом на обвязку плюс
лимит output tokens; при превышении $0.002 запрос отклоняется до обращения к LLM.
Стоимость успешного вызова учитывается и после ошибки guard. Сетевые ошибки и
таймауты могут тарифицироваться провайдером; его bill — источник истины.
Автоматических повторов нет; поддерживается mock.

## Корпоративный TLS-прокси

Обычный Compose не требует host CA bundle. Dockerfile поддерживает необязательный
BuildKit secret для корпоративного сертификата:
docker build --secret id=proxy_ca,src=/path/to/trusted-ca.pem -t support-copilot .

Для живого LLM через прокси отдельно подключите PEM bundle в контейнер и задайте
SSL_CERT_FILE, HTTPS_PROXY и при необходимости NO_PROXY. Не отключайте TLS-проверку.
Сертификат и ключи не включать в образ/Git.

## Ограничения

Реальных rules/taxonomy/тикетов нет. Модули B/C/D — заглушки. Синтетические
измерения не оценивают качество или стоимость реальной генерации.
Sync timeout не останавливает произвольный сторонний код; модули обязаны соблюдать
бюджет. Дедуп локален процессу, имеет лимит 10000 записей; batch сортировать по
created_at. Бонусная админка — после готовности предметного ядра и метрик.
