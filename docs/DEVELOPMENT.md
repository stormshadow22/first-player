# Запуск

Python 3.11; `make install`, `make run`. API: POST /triage и GET /health.
`make test lint smoke` проверяет контракт, ошибки стадий, таймауты, провайдер,
батч и HTTP-запуск. `docker compose up --build` запускает контейнер.
Используйте имеющийся checkout; не создавайте worktree без просьбы пользователя.

`make predict IN=data/tickets_valid.jsonl OUT=reports/raw/pred.jsonl`
Поддерживаются .jsonl.gz; роли admin/reported_player исключаются. Некорректные
строки пропускаются с номером строки, итоговые счётчики выводятся в журнал.
Результаты пишутся сразу по готовности; порядок не гарантирован.
`make bench` измеряет HTTP на 400 синтетических тикетах.
Для реальных данных: `.venv/bin/python -m scripts.bench --input data/tickets_valid.jsonl`.
Метрики локальны одному процессу и экспортируются при штатной остановке API
или завершении predict в reports/raw/metrics.json. Bench пишет bench.json.
Синтетика проверяет инфраструктуру, но не качество классификатора, RAG и LLM.

Дедуп: DEDUP_ENABLED=1 (по умолчанию 0). Сервис использует wall clock,
батч — created_at и один проход входных данных. Для детерминированного результата
по времени входной файл должен быть отсортирован по created_at. Сходство —
cosine bag-of-words >=0.85, окно 60 минут, максимум 10000 записей на процесс.
Разные процессы/реплики не делят хранилище. Без reporter_hash используется
точный хеш нормализованного текста. Дедуп не заменяет модерацию спама.

# LLM

По умолчанию генератор — безопасная заглушка и вообще не вызывает LLM.
LLM_MOCK=1 позволяет C тестировать интеграцию без ключа.
Для реального провайдера: LLM_PROVIDER=anthropic|openai_compatible,
LLM_MODEL, LLM_API_KEY, LLM_BASE_URL (необязателен),
LLM_PRICE_IN_PER_MTOK и LLM_PRICE_OUT_PER_MTOK обязательны. Цены — USD за миллион
токенов; они не зашиты в код. Кандидат дешёвой модели — gpt-4.1-nano, но
актуальная доступность и цена не подтверждены: официальный pricing URL вернул
HTTP 403 из облачной среды. Перед использованием сверить https://openai.com/api/pricing/.
Пока это не сделано, оставлять mock/локальную заглушку.
OpenAI prompt caching работает автоматически у поддерживаемых моделей;
Anthropic caching включается LLM_PROMPT_CACHE=1. Для него настройте input price
как верхнюю границу с учётом cache-write тарифа. Метрики стоимости консервативны:
скидки cache-read не вычитаются. Предварительный лимит — $0.002 на запрос.
Прайс провайдера и фактический счёт биллинга остаются источником истины.
Повторных HTTP попыток нет: ограничение одного вызова важнее повторов.

# Ограничения

Пока нет реальных данных, правил и моделей. make eval/index/train — entrypoints
для файлов владельцев D/C/B. Админ-интерфейс отложен: ядро предметной логики
остаётся заглушкой. Модули обязаны соблюдать бюджет; отмена thread-обёртки
останавливает ожидание, но не произвольный синхронный код внутри сторонней модели.
Для неконтролируемых CPU-задач потребуется отдельный process worker.

Compose передаёт host CA bundle как BuildKit secret, не сохраняя его в образ.
На машине без /etc/ssl/certs/ca-certificates.crt задайте SUPPORT_CA_BUNDLE
путём к доверенному PEM bundle. Для живого LLM в контейнере отдельно передайте
настройки провайдера, HTTPS proxy и runtime CA; текущий Compose проверен в mock.
Тома data/ и models/ доступны read-only, reports/raw/ сохраняется на хосте.
/metrics возвращает статистику текущего процесса; bench использует разницу
суммарной стоимости до и после прогона. Запускать без посторонней нагрузки.
